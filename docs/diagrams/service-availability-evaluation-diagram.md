# Діаграма оцінювання доступності сервісу

Компактна Mermaid-діаграма для Рисунка 3.2 у пояснювальній записці. Деталі кожного етапу пояснюються в §3.4, тому на рисунку залишено лише основну послідовність обчислень.

```mermaid
flowchart LR
    A["Вхідні дані<br/>сервіси, пристрої,<br/>резервне живлення, H"]
    B["Оцінювання<br/>автономності"]
    C["Симуляція<br/>залежностей"]
    D["Результат<br/>статус, час, причина"]

    A --> B --> C --> D
```

На етапі оцінювання автономності система обчислює часову доступність компонентів сценарію. Далі модуль симуляції поширює ці часові обмеження через граф обов'язкових функціональних залежностей і формує тривалість доступності сервісу, його статус та причинне пояснення.

Канонічні правила розрахунку: `docs/specs/user-facing-mvp-v1.md`, `docs/SIMULATION.md`, `apps/web/src/user-mvp/` і `apps/web/src/simulation/`.
